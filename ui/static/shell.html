Game servers

one at a time

Only one game runs at a time. CS2 is allocated 8 GB and Minecraft 11 GB on a machine with about 17 GB usable, so running two would not merely be slow — the kernel would kill one of them, usually mid‑save. Starting a game stops whatever is already up, and asks before it does.
